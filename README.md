# Capstone.Project.Coursera
This is the final project for the IBM Data Analyst Professional Certificate course. The project focuses on currently popular technologies and forecasts future usage trends based on data from a programming website, categorized by demographics.
Technologies used:
Python (pandas, matplotlib, seaborn, BeautifulSoup)
SQL
Looker Studio

The project is structured according to the stages of data analysis:
1. Data collection
2. Data wrangling
3. Exploratory data analysis
4. Data visualization
5. Dashboard creation
